# Hướng dẫn sử dụng (cho người dùng cuối)

Tài liệu từng bước cho nhân viên cửa hàng, viết bằng tiếng Việt, dùng đúng nhãn trên màn hình. Khác với `docs/business/` (nghiệp vụ, yêu cầu, UAT) và `docs/frontend/` (cho lập trình viên).

| Màn hình | Hướng dẫn |
|---|---|
| Mọi màn hình đã làm mới: hộp thoại, lỗi, thông báo kết quả, danh sách trống | [common-screen-behaviour.md](common-screen-behaviour.md) |
| Dữ liệu chủ (17 màn hình: phòng ban, chức vụ, nhân viên, địa lý, tiền tệ…) | [masterdata.md](masterdata.md) |
| Sản phẩm (sản phẩm, thương hiệu, danh mục, thuộc tính, bảng giá, biến thể, hình ảnh) | [products.md](products.md) |
| Nhân sự (chấm công, nghỉ phép, bảng lương, hồ sơ lương, thiết lập lương, ca làm việc) | [hrm.md](hrm.md) |
| Khách hàng (CRM: liên hệ, khách hàng tiềm năng, cơ hội, yêu cầu hỗ trợ, hoạt động) | [crm.md](crm.md) |
| Tồn kho (tồn kho, kho hàng, vị trí, điều chỉnh, kiểm kê, chuyển kho, mã vạch, chốt định giá) | [inventory.md](inventory.md) |
| Người dùng, Vai trò, Đơn vị (mời, khóa, vai trò và quyền, đơn vị) | [identity.md](identity.md) |
| Cài đặt → Vận chuyển (quy tắc chọn hãng, bảng phí giao hàng) | [shipping-settings.md](shipping-settings.md) |
| Cài đặt → Thông báo đã gửi | [notification-history.md](notification-history.md) |
| Mua hàng (đơn hàng mua, yêu cầu báo giá, hóa đơn nhà cung cấp, trả hàng, dung sai đối chiếu) | [purchasing.md](purchasing.md) |
| Thanh toán (hoàn tiền), Vận đơn, Chính sách hoa hồng, Nhật ký hệ thống | [payments-shipping-sales-logs.md](payments-shipping-sales-logs.md) |
| Kế toán → Thuế suất, Kỳ kế toán, Hệ thống tài khoản, Tài khoản ngân hàng (đối chiếu sao kê) | [accounting-setup.md](accounting-setup.md) |
| Kế toán → Bút toán, Hóa đơn mua, Hóa đơn bán (duyệt, thanh toán, hóa đơn điện tử, đánh giá lại ngoại tệ) | [accounting-postings.md](accounting-postings.md) |
| Cài đặt (25 màn hình) và Đăng nhập (xác thực hai bước, đăng nhập bằng nhà cung cấp) | [settings-and-sign-in.md](settings-and-sign-in.md) |
| Cửa hàng trực tuyến cho khách mua hàng (duyệt, giỏ hàng, thanh toán 3 bước, đăng nhập, tài khoản, dùng trên điện thoại) | [storefront.md](storefront.md) |
| Ứng dụng di động cho khách mua hàng (đăng nhập, tìm kiếm, giỏ hàng, đơn hàng, ngôn ngữ) | [mobile-customer.md](mobile-customer.md) |
| Ứng dụng di động cho nhân viên (bán hàng POS, tồn kho, giao hàng) | [mobile-staff.md](mobile-staff.md) |
| Vận chuyển → Hoàn hàng | [shipping-returns.md](shipping-returns.md) |
| Cài đặt → Webhook | [notification-webhooks.md](notification-webhooks.md) |
| Cài đặt → Mẫu thông báo | [notification-templates.md](notification-templates.md) |

Quy ước khi thêm hướng dẫn: nêu ai dùng được (quyền bằng lời), vị trí trong menu, ý nghĩa cột / nút, các việc thường làm theo bước đánh số, thông báo lỗi và cách xử lý, giới hạn đã biết (số rủi ro trong DEFERRED-ISSUES). Ảnh chụp màn hình thêm sau khi duyệt thử trên trình duyệt.
