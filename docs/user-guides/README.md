# Hướng dẫn sử dụng (cho người dùng cuối)

Tài liệu từng bước cho nhân viên cửa hàng, viết bằng tiếng Việt, dùng đúng nhãn trên màn hình. Khác với `docs/business/` (nghiệp vụ, yêu cầu, UAT) và `docs/frontend/` (cho lập trình viên).

| Màn hình | Hướng dẫn |
|---|---|
| Mọi màn hình đã làm mới: hộp thoại, lỗi, thông báo kết quả, danh sách trống | [common-screen-behaviour.md](common-screen-behaviour.md) |
| Dữ liệu chủ (17 màn hình: phòng ban, chức vụ, nhân viên, địa lý, tiền tệ…) | [masterdata.md](masterdata.md) |
| Vận chuyển → Hoàn hàng | [shipping-returns.md](shipping-returns.md) |
| Cài đặt → Webhook | [notification-webhooks.md](notification-webhooks.md) |
| Cài đặt → Mẫu thông báo | [notification-templates.md](notification-templates.md) |

Quy ước khi thêm hướng dẫn: nêu ai dùng được (quyền bằng lời), vị trí trong menu, ý nghĩa cột / nút, các việc thường làm theo bước đánh số, thông báo lỗi và cách xử lý, giới hạn đã biết (số rủi ro trong DEFERRED-ISSUES). Ảnh chụp màn hình thêm sau khi duyệt thử trên trình duyệt.
